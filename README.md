# ManuMind AI

This repository contains the ManuMind AI project (frontend and backend). Push target: https://github.com/manoranjith0808/ManuMind-AI

Quick setup

- Frontend: Next.js app in `frontend/`
- Backend: Python FastAPI in `backend/`

To create the GitHub repository and push from your machine (recommended):

Using `gh` (GitHub CLI):

```bash
gh repo create manoranjith0808/ManuMind-AI --public --source=. --remote=origin --push
```

Or manually:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/manoranjith0808/ManuMind-AI.git
git push -u origin main
```
